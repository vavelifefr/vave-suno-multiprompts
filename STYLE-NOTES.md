# STYLE-NOTES.md — mutable style registry for vave-suno-multiprompts (Pro runtime)

- Version: 2026-09-12. Language: English. Same folder as SKILL.md.
- Status: MUTABLE knowledge base (the only accumulating file in the skill). `GUIDE.md` is the immutable manual — it never stores style vocabulary; every reusable style note lands HERE, one stamped entry per requested style, added on demand.
- Edit discipline: maintenance mode on explicit order ONLY (see SKILL.md Modes) — never during track work. A "good style worth remembering" with no order becomes a one-line chat note, not a silent entry.
- Read policy: read once per window alongside GUIDE core; consult entries by slug per style request. Full re-read only when entries changed mid-window (announced by the editor).
- Cap: 30000 chars including spaces. On overflow compress oldest/lowest-value entries first (FIFO by last-usefulness, never the entry shape or this header).
- Hard boundary: entries hold reusable production vocabulary — never artist names, never lyric chunks, never single-song breakdowns (those stay in chat/INFO).

## Rule

A style request with no direct note below and no sufficient mechanics answer in GUIDE.md → targeted web inside the LINKS.md network policy → add the source link (LINKS.md §2/§3/§4 by kind) + exactly one note in this shape.

## Entry shape

### `style-slug` — source: <URL> (synced DD.MM.YYYY)

- anchors: subgenre + era pin (production signatures, no names)
- rhythm/drums: recipe + feel
- bass: design + lock
- hero/texture: 2-3 instruments, room, mix cues
- vocal: role/texture/delivery/mix fingerprint
- mood seed: one-tension trio
- BPM corridor: number or narrow range
- exclude starters (≤3): most likely bleeders
